# Interval Timer

Interval-training timer with per-set exercise/rest times.

- `interval-timer.html` – browser version (single file)
- `IntervalTimerIOS/` – native SwiftUI iPhone app (iOS 17+) with lock-screen/Dynamic Island Live Activity, plus a companion Apple Watch app (watchOS 10+) that syncs settings from the phone. See `IntervalTimerIOS/README.md` for setup. `genproj.py` regenerates the Xcode project.
